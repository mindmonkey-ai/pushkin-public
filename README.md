# Pushkin

Pushkin checks coding-agent changes against project contracts and runs repository
quality gates. It helps teams keep their declared constraints in the development
workflow.

This is the public documentation and support home for Pushkin, not a source repository.
The implementation is maintained privately. Public distribution uses prebuilt
binaries; installing Pushkin does not require access to its source repository.
