# Security reporting

Do not open a public issue for a suspected vulnerability or disclose an exploit
in a public discussion.

Use this repository's Security tab and select
**Report a vulnerability** to send a private report through GitHub. If that button
is unavailable, do not post vulnerability details publicly. Private vulnerability
reporting is enabled for this repository; signing in to GitHub is required to
submit a report.

Include the affected version, platform, installation method, impact, and a
minimal reproduction. Remove secrets and unrelated proprietary code. Share only
information you are authorized to disclose.

Coordinate disclosure privately with the maintainer. No response deadline or
supported-version window is promised by this initial documentation.
