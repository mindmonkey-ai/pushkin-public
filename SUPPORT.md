# Support

Use the Issues tab of this public support repository for non-security bugs,
installation problems, and feature requests.
Search existing issues before opening a new one.

Include:

- Pushkin version and installation method.
- Operating system, CPU architecture, and Linux libc where applicable.
- The command you ran, expected result, and actual error.
- A minimal, sanitized reproduction that you are authorized to share.

Do not upload proprietary source, credentials, access tokens, private repository
URLs, or unsanitized logs. Remove usernames and sensitive local paths. Prefer a
small synthetic example over a copy of your real project.

For vulnerabilities, follow [private security reporting](SECURITY.md) instead.
Support is best-effort; this documentation does not promise a response deadline.
